# SQL Data Analysis

SQL practice queries completed as part of a data analysis course.

## What's covered
- Aggregation with `GROUP BY`, `HAVING` and aggregate functions
- Joins across multiple tables
- Subqueries
- Sorting and limiting results
- String and date functions such as `LEFT` and `EXTRACT`
